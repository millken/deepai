# DEEPAI.md

## 交流
- 使用中文，回答要简短专业
- 每次回答运用第一性原理，并进行对抗式审查。

## 编码
- 只实现明确要求的功能，不添加：额外配置项，不必要的抽象层，不可能发生的错误处理。
- 自检：资深工程师是否会认为代码过度复杂？若是，简化
  
## 修改代码
- 只改必须改的部分
- 保持代码风格一致
- 不要过多添加注释，用代码说话。
- 发现无关死代码提出建议，但不主动删除
- 不要自动 commit 或 push，除非用户明确要求

## Guidelines
- Write clean, idiomatic code
- Follow existing project conventions
