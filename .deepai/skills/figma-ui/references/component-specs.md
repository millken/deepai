# 控件尺寸规格与验收不变量

AI 搭控件最常见的失败是「目测凑数」:按钮高度、字号、内边距各自随手取值,比例失调;文字靠手摆坐标而不是 auto-layout 居中。
本文件给出**先定规格、再按规格构建、最后量测验收**所需的数据。规格取值参照主流设计系统的交集(Tailwind/shadcn、Ant Design、Material 3、Apple HIG),项目或设计文件已有规格时以已有为准。

## 1. Button

| Size | 高度 | 水平内边距 | 字号/行高 | 字重 | 圆角 | 图标 | 图标-文字间距 |
|---|---|---|---|---|---|---|---|
| sm | 32 | 12 | 14/20 | 500 | 6 | 16 | 6 |
| md | 40 | 16 | 14/20 | 500 | 8 | 16 | 8 |
| lg | 48 | 20 | 16/24 | 600 | 8 | 20 | 8 |
| 移动端主按钮 | 48 | 16(通常撑满宽) | 16/24 | 600 | 8–12 | 20 | 8 |

构成公式(auto-layout HUG 高度):**高度 = 行高 + 2 × 垂直内边距**。md:20 + 2×10 = 40。不要先定高度再手摆文字。
仅图标按钮:宽 = 高(正方形),图标居中,内边距 = (高 − 图标) / 2。

## 2. Input / 文本框

| Size | 高度 | 水平内边距 | 字号/行高 | 圆角 | 描边 |
|---|---|---|---|---|---|
| sm | 32 | 10 | 14/20 | 6 | 1px |
| md | 40 | 12 | 14/20 | 8 | 1px |
| lg | 48 | 14 | 16/24 | 8 | 1px |

- 内部结构:`[前置图标] 文本 [后置图标]` 水平 auto-layout,交叉轴 CENTER;文本节点 `FILL` 宽度、单行。
- 字段标签在输入框**外部**上方,与输入框间距 6–8;帮助/错误文字在下方,间距 4–6,字号 12/16。
- 状态变体:default / focus(描边加深或 2px 品牌色)/ error(描边错误色 + 错误文字)/ disabled(降低对比度),**各状态几何尺寸完全一致**。
- 移动端 Web 的输入字号 ≥ 16,否则 iOS Safari 聚焦时会自动放大页面(代码侧约束,设计稿应一致)。

## 3. 验收不变量(recipes §8 脚本逐条量测)

| 级别 | 检查 | 判定 |
|---|---|---|
| error | 控件用 auto-layout 构建 | Button/Input 必须 `layoutMode=HORIZONTAL` |
| error | 内容居中 | Button 两轴 `CENTER`;Input 交叉轴 `CENTER` |
| error | 文字行框几何居中 | 文字行框中心与控件中心偏差 ≤ 0.5px(Button 水平方向看内容整体) |
| error | 内边距对称 | Button 左=右、上=下 |
| error | 标签单行不换行 | 文字框高 ≤ 行高 × 1.2 |
| error | 字号/高度比 | 0.25–0.5 之外(如 40 高配 24px 字、60 高配 12px 字) |
| error | 水平内边距/高度比 | 0.2–1.0 之外 |
| error | 宽度 ≥ 高度 | 非仅图标按钮 |
| error | Input 有边界 | 有描边或与背景不同的填充 |
| error | 文字对比度 | 正文 < 4.5:1;大字(≥24px,或 ≥18.66px 粗体)< 3:1 |
| error | 字体缺失 / 中文用了无中文字形的字体 | `hasMissingFont`;含中日韩字符但字体不是 PingFang / Noto Sans CJK / 思源等 |
| error | 文字被裁切/溢出 | 渲染区域超出文字框或超出父容器 |
| error | 同一组件集同 size 的变体高度不一致 | 按 `size=` 分组比较 |
| error | 流式子级溢出 | auto-layout 父级里非 absolute 子级超出父级边界 |
| error | 文字重叠 | 非 auto-layout 父级里两个含文字的兄弟节点相交 |
| error | 验收截断 | 子树超过 3000 节点,`pass` 强制为 false,拆小重跑 |
| error | 胶囊收缩 | 上下 padding 均为 0 且高度 ≈ 文字行高(±2px)——AUTO 收缩贴文字;仅高 <18 为 warn(紧凑角标/tag 合法) |
| error | 胶囊文字垂直居中 | 胶囊(pill/chip/tag,圆角≥高/2)文字中心与胶囊中心偏差 ≤ 1px |
| error | 图标栈水平居中 | 纵向图标+文字小栈(宽≤80)的文字/图标中心与栈中心偏差 ≤ 1px |
| error | 图标矢量边界 | 图标框(14–32 方形)内矢量联合 bbox 不越界,长边充满 ≥ 60% |
| warn | 字号/高度比 0.28–0.45、内边距比 0.3–0.65 之外 | 偏离常见比例,需有意为之 |
| warn | 高度不在 24/28/32/36/40/44/48/52/56 | 非标准档 |
| warn | 视觉(字形墨迹)中心偏差 > max(1.5, 0.12×字号) | 字体度量或回退字体导致的视觉不居中 |
| warn | 行高为 AUTO | 应显式设像素行高,否则高度随字体漂移 |
| warn | 高度 < 44 | 所在屏幕画板宽 ≤480 时报(移动端触控目标);组件集与桌面画板不报 |
| warn | 近似未对齐 | 非 auto-layout 兄弟节点的左/右/上边相差 0.5–3px |

结果的 `checked` 给出实际覆盖的节点/文字/控件数:构建了控件却 `controls:0` 说明命名未被识别,此时 `pass:true` 不能证明控件正确。
控件识别靠命名:节点名或其主组件名匹配 `button|btn|按钮` → Button;`input|field|textfield|search|输入|搜索` → Input。所以图层/组件必须按职责英文语义命名(SKILL「Figma 设计端规范」)。
